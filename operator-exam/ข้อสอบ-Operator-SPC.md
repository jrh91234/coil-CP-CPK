- ข. ทุก 2 ชม.
- ค. ทุก 3 ชม.
- ง. ทุก 4 ชม.

**5.** 🟢 (E) หัวข้อที่ต้องตรวจในการตรวจสภาพภายนอก (Appearance) คืออะไร
- ก. สีชิ้นงาน และ น้ำหนัก
- ข. บิดงอ/เสียรูป และ รอยขีดข่วนที่ตัวงาน
- ค. สนิม และ คราบน้ำมัน
- ง. ความยาวรวม และ เส้นผ่านศูนย์กลาง

**6.** 🟢 (F) การ์ด Cpk บนหน้า Dashboard เป็น "สีเขียว" เมื่อค่า Cpk เป็นเท่าใด
- ก. Cpk < 1.00
- ข. 1.00 ≤ Cpk < 1.33
- ค. Cpk ≥ 1.33
- ง. Cpk = 0

**7.** 🟡 (G) บันทึกผลตรวจสภาพภายนอกแล้วพบชิ้นงานบิดงอ (NG) สิ่งที่ต้องทำคือข้อใด
- ก. ไม่ต้องบันทึก เพราะจะทำให้ยอด NG สูง
- ข. เลือก "ไม่ผ่าน" ในข้อนั้น กรอกหมายเหตุ แล้วแจ้งหัวหน้างาน
- ค. เลือก "ผ่าน" ไปก่อน แล้วค่อยแจ้งหัวหน้าทีหลัง
- ง. ถ่ายรูปใหม่จนกว่าจะดูไม่ออกว่าบิด
